Python Installation

Check current Python version

Before you can begin writing Python code, you’ll need the Python interpreter that compiles and runs your code, and a code editor with features that can help you write Python code.

We will be using Python 3 for this course, so to check, Python 3 installed on my computer, already, follow the instrations for your Operating System:

  • Windows
  • macOS
  • Linux

To determine if your Windows computer already has Python 3:

  1. To open the Command Prompt app, go to Start on the Windows Taskbar.

  2. Enter cmd in the Windows search box and select the Command Prompt App in the Best match results.

  3. Enter the following command and then press Enter:

    python –version

To determine if your macOS computer already has Python 3 installed:

  1. Open the Terminal app by pressing Command + Spacebar key combination to search by using Spotlight.

  2. In the search box, enter Terminal. In the results set select Terminal app, and then press Return to start the app.

  3. At the command prompt, enter the following command:

python –version

Python is pre-installed on most Linux distributions (like Ubuntu). To determine if your Linux computer already has Python 3 installed:

  1. Open a Linux terminal session.

  2. Enter the following command and then press Enter.

python –version

Running python --version may not return a value, or may return an error message stating ‘python’ is not recognized as an internal or external command, operable program or batch file. This indicates Python is not installed on your Windows system.

But, if you see the word Python with a set of numbers separated by . characters, some version of Python is installed. Here’s an example of the output you might see:

Python 3.11

As long as the first number is 3, you have Python 3 installed on your computer. If not, you’ll need to install Python 3. We’ll walk you through installation of Python 3 in the next section.

Installation of Python 3

Note

At the time of writing this document, Python 3.11 was the latest version available, so instructions here refer to that version. Install the latest version of Python that is available for your operating system. If you install a different version, the button labels and the filenames may differ slightly from the installation instructions.

  • Windows
  • macOS
  • Linux
  1. To install Python from python.org, use the Download Python button that appears first on the page to download the latest version.
Note

Make sure that you have admin access for installing the latest version of the Python on Windows.

  1. Execute the file that you have downloaded. This program must be run with your computer’s administrator privileges, so be prepared to enter your appropriate password if asked. Click on the option:

Add Python 3.11 to PATH (or its Mac/Linux equivalent)

Pay close attention to where on your computer Python is installed and write it down.

The system install of Python on macOS is not supported. Instead, a package management system like Homebrew is recommended. To install Python using Homebrew on macOS use brew install python3 at the Terminal prompt.

Note

On macOS, make sure the location of your VS Code installation is included in your PATH environment variable.

The built-in Python 3 installation on Linux works well, but to install other Python packages you must install pip with apt or dnf package mangement depending on your Linux versions.
